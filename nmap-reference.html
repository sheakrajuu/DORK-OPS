REFERENCE / NETWORK MAPPING

Nmap options

A categorized quick reference to common Nmap flags. Categories and cards are generated from one local option catalog.

Authorization required: Nmap sends network probes. Use it only within an explicitly authorized scope, follow the owner’s rate and timing requirements, and verify options against the official Nmap manual. Examples use placeholders such as <target ip>; replace every placeholder with an authorized value before running a command. This reference omits spoofing, decoys, evasion, relay, and exploit-oriented script examples.

Safe lab: To learn, use a machine you control or Nmap’s explicitly provided Scanme test host and follow its usage limits. Do not scan arbitrary public targets.
NOTE: Scan results are point-in-time observations, not proof that a host or service is secure.DORK OPS · REFERENCE
