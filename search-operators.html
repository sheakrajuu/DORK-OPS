REFERENCE / GOOGLE SEARCH

Search operators

A practical reference to query operators, with examples you can copy or run in Google Search.

Coverage note: Google does not publish a complete list of every query parser or historical “dork.” This catalog combines current Google documentation with community-listed syntax from GitHub. Community and retired forms are labeled separately because their behavior may be unsupported or inconsistent; this is a broad reference, not a guarantee that every form works.

Common search operators

These operators and search refinements are documented in Google Search help. Keep the value immediately next to the operator (for example, site:example.org).

"exact phrase"Exact phraseDocumented

Search for words together in the exact order entered.

"annual sustainability report"
Search
-termExclude a wordDocumented

Remove results containing a word or phrase by putting a minus sign directly in front of it.

site:example.org annual report -draft
Search
OREither termDocumented

Find results containing either alternative. Write OR in uppercase.

site:example.org contact OR about
Search
site:Limit to a site or domainDocumented

Show results from a particular site, domain, URL, or URL prefix.

site:example.org public reports
Search
filetype:Find a file typeDocumented

Filter results to a document type such as PDF, CSV, or PPTX.

site:example.org filetype:pdf annual report
Search
before: after:Filter by dateDocumented

Filter documents by last-updated date or year. Combine both to define a range.

site:example.org policy after:2024-01-01 before:2025-01-01
Search

Additional operators

These commonly circulated query forms are not all documented by Google and may behave inconsistently. Treat the status labels as guidance, not a guarantee.

intitle:Match a page titleLimited / undocumented

Look for a word in the page title.

site:example.org intitle:policy
Search
allintitle:All terms in the titleLimited / undocumented

Ask for all following terms to appear in the page title.

allintitle:annual sustainability report
Search
inurl:Match a URL termLimited / undocumented

Look for a word in the result URL.

site:example.org inurl:about
Search
allinurl:All terms in a URLLimited / undocumented

Ask for all following terms to appear in the result URL.

allinurl:news archive
Search
intext:Match page textLimited / undocumented

Look for a word in the indexed text of a page.

site:example.org intext:accessibility
Search
allintext:All terms in page textLimited / undocumented

Ask for all following terms to appear in the indexed page text.

allintext:public contact accessibility
Search
inanchor:Match link textLimited / undocumented

Look for a word in the text used by links pointing to a result; availability varies.

inanchor:accessibility resources
Search
allinanchor:All terms in link textLimited / undocumented

Look for results with all following terms in incoming link text; availability varies.

allinanchor:public research guide
Search
*Phrase wildcardContext-dependent

In some quoted searches, an asterisk can stand in for unknown words.

"responsible disclosure * policy"
Search
AROUND(n)Nearby termsUndocumented

Search for terms appearing near one another; support and results can vary.

site:example.org security AROUND(4) contact
Search
..Number rangeContext-dependent

Some Google searches accept two dots between numbers to indicate a range.

site:example.org report 2022..2025
Search
ext:File extension aliasUndocumented alias

Commonly used as an alternative spelling for filetype:; prefer Google's documented form.

site:example.org ext:pdf annual report
Search
number..numberNumeric rangeContext-dependent

Some query examples use two dots between numbers as a range; results may be treated as ordinary text.

camera $200..$500
Search
define:Dictionary lookup shortcutSearch shortcut

Historically used to request a definition. Google may instead interpret this as a normal query or show a search feature.

define:encryption
Search
( )Group alternativesQuery syntax

Group related alternatives to make a longer query easier to read; how Google interprets grouping can vary.

site:example.org (accessibility OR inclusion)
Search
ANDCombine termsUsually implicit

Google generally combines ordinary search terms without needing an explicit AND keyword.

site:example.org research policy
Search

Google Images operators

These are for Google Images and may not work in regular web search.

imagesize:Find image dimensionsGoogle Images

Find images with a specific width and height.

imagesize:1200x800 landscape
Search Images
src:Find pages referencing an imageGoogle Images

Look for pages that reference an image URL in its source attribute.

src:https://example.org/images/logo.png
Search Images

Google News operators

These source filters are commonly reported for Google News but are not listed in Google's general operator reference. Availability can vary; the buttons search Google News for you to verify.

source:Limit to a news sourceProduct-specific / verify

Search Google News for stories associated with a publication.

Search News
location:Limit by locationProduct-specific / verify

Search Google News for coverage associated with a place.

Community-listed and unverified syntax

These forms appear in community cheat sheets, including GitHub repositories, but are not in Google's current operator documentation. They are included for recognition and testing, not as supported features. Prefer documented syntax where noted.

|OR symbol aliasCommunity-listed / verify

Some lists use a pipe as an alternative to uppercase OR. Use OR, which Google's help documents.

site:example.org contact | about
Search
numrange:Numeric range aliasUndocumented / verify

Community lists describe this as a number-range filter. It is not in Google's current operator reference; range syntax may also be treated as ordinary query text.

numrange:33-43 product
Search
author:Author filterUnverified

Listed in some community references, but not a documented general Google Search operator. Do not rely on it to identify authors.

author:Alex public research
Search
contains:Linked file-type filterUnsupported / unverified

Sometimes claimed to find pages linking to a file type. Google does not document this as a current Search operator.

contains:pdf public report
Search
date:Relative date filterUnsupported / unverified

Community lists sometimes claim a month-based date filter. Prefer the documented before: and after: operators.

date:3 public policy
Search
inpostauthor: allinpostauthor:Blog author filtersLegacy / unsupported

These occur in older lists for discontinued or product-specific blog search. They are not current general Google Search operators.

inpostauthor:Alex public research
Search
@platformSocial platform filterCommunity-listed / verify

Some cheat sheets describe an at-sign shortcut for social platforms. It is not included in Google's documented operator list; use site: to scope a search when appropriate.

@instagram public profile
Search
weather: stock:Search feature triggersShortcuts, not operators

Community lists sometimes group these with operators. They are query shortcuts for Google features, not reliable general-purpose filters; availability and result presentation can change.

weather:Toronto
Search

Retired or unsupported operators

These appear in older cheat sheets. They are not reliable Google Search operators today; they are listed so you can recognize outdated examples.

cache:Cached pageRetired

Google removed its cached-page feature. Use the website itself or a legitimate web archive when appropriate.

cache:example.org
link:Pages linking to a URLUnsupported

Legacy link-search syntax; Google Search does not provide this as a supported backlink operator.

link:example.org
related:Similar websitesRetired

This old related-sites operator is no longer a dependable Google Search feature.

related:example.org
info:Page informationRetired

Older Google info-page shortcut; do not expect it to return the historic information panel.

info:example.org
phonebook:Phone directory lookupRetired

Obsolete syntax associated with a discontinued phonebook feature.

phonebook:example.org
+termForce an exact termRetired

The old plus-for-inclusion behavior was retired. Use quotes around a word or phrase when seeking an exact match.

+"exact phrase"
~termSynonym searchRetired

The old tilde synonym operator is not supported as a special Google Search operator.

~reliable information
daterange:Julian date rangeUnsupported

Often repeated in old dork lists but not a documented current Google Search operator. Prefer before: and after:.

daterange:2459000-2459030
