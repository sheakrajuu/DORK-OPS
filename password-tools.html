Password-tool options

A searchable quick reference to common Hydra, John the Ripper, and Hashcat command-line options, with examples limited to local labs and authorized offline audits.

Use the official manuals: Options differ across releases and builds. This is a curated quick reference, not an exhaustive specification. Hydra examples use a loopback lab placeholder; John and Hashcat examples use placeholders for locally held test files. Do not use credentials or hashes without authorization.

Start here: what each tool does

Choose the tool based on what you are testing. These tools work in different ways, so their inputs and options are not interchangeable.

Hydra: online service checks

Hydra connects to a login service and submits candidate credentials. That creates network traffic and may trigger account lockouts. In this site, command examples are for an isolated service on 127.0.0.1 only; do not change the target to a public or third-party system.

John: offline hash audit

John reads a local hash file and tests candidates against it without contacting a login service. Select a format only when auto-detection is not suitable and you have verified the hash format from an authorized source.

Hashcat: offline hash audit

Hashcat also tests candidates against a local hash file. Its -m value identifies the hash format; the number must match the data. The same input file can produce misleading results if the selected format is wrong.

Read a command from left to right

john --wordlist='wordlist.txt' 'authorized-hashes.txt'
  1. john starts the John program.
  2. --wordlist=... tells it where the local candidate list is. The quoted text is a file path, not the list contents.
  3. authorized-hashes.txt is the local input file being audited.
  4. Quotes keep a path with spaces together as one argument. Replace the example paths with files you are authorized to use.

A hash is a one-way representation used for verification, not an encrypted password to decrypt. Recovered results and source hashes are sensitive; protect them and follow your approved handling rules.
